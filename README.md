Sladolino 🍦
Sladolino je web aplikacija namenjena upravljanju ponudom i naručivanju sladoleda. Aplikacija omogućava korisnicima pregled dostupnih ukusa, dok administratori mogu dodavati, uređivati i brisati proizvode.

📁 Struktura projekta
index.php – Glavna početna stranica aplikacije

assets/ – Staticki resursi (CSS, slike, JavaScript)

models/ – PHP logika za rad sa bazom podataka

views/ – HTML/PHP logika za prikaz stranica

data/ – Dodatni podaci ili skripte

sladolino.sql – SQL skripta za kreiranje baze podataka

Dokumentacija.pdf – Detaljna dokumentacija projekta

🛠 Tehnologije
Backend: PHP

Frontend: HTML, CSS, JavaScript

Baza podataka: MySQL

🚀 Pokretanje aplikacije lokalno
Kloniraj repozitorijum:
git clone https://github.com/Nikola-1/sladolino.git
Postavi projektni folder u lokalni server:

Ako koristiš XAMPP, premesti folder u htdocs direktorijum.

Pokreni Apache i MySQL servise.

Importuj bazu podataka:

Otvori phpMyAdmin.

Kreiraj novu bazu pod nazivom sladolino.

Importuj sladolino.sql fajl koji se nalazi u root direktorijumu projekta.

Pokreni aplikaciju:

U browseru otvori: http://localhost/sladolino

🔐 Funkcionalnosti
Pregled dostupnih sladoleda

Dodavanje novih ukusa (admin)

Uređivanje i brisanje postojećih ukusa (admin)

Osnovna navigacija kroz aplikaciju
